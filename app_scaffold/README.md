# 🚀 `app_scaffold` Mason Brick

A complete Clean Architecture project initialization brick for Flutter applications.

## Features
- **Clean Architecture Scaffolding**: `lib/core/` (Network, Storage, Design System, Router, L10n, DI, Extensions).
- **12 Production Packages**: `bloc`, `flutter_bloc`, `get_it`, `go_router`, `flutter_screenutil`, `flutter_svg`, `dartz`, `equatable`, `dio`, `flutter_dotenv`, `shared_preferences`, `flutter_secure_storage`.
- **Educational Demo Feature**: Complete `sample` feature replicating `mobile_feature_template` feature architecture 1:1.

## Quick Usage

```bash
mason add app_scaffold --path /path/to/app_scaffold
mason make app_scaffold
```
